### W2-G4 recommendation — 2026-11-15

- **Steam and Epic:** Retain the direct readers. Steam app IDs and validated library/install paths already supply identity. Epic's parsed manifest supplies the exact launch executable used for launcher and renderer checks. Keep alternate-library, malformed-entry and launcher-handoff fixtures for both. Missing and unreadable sources need distinct outcomes when a cache exists.
- **GOG first:** Prototype a small direct reader using read-only Registry32 HKLM access. GameFinder 4.9.0 reads the product ID, name, path, build ID and parent ID and returns per-entry errors. Key by GOG product ID, treat DLC separately, validate canonical local install paths, and require independent executable eligibility. Test absent/denied keys, malformed rows among valid ones, duplicates, DLC, changed paths and offline retention using injected registry fixtures. The direct reader avoids adding the GameFinder package graph. The evaluated alternative is GPL-3.0, tag `v4.9.0` at `efa23bd6d02ec07aa9fb1abe1025efafe3190d9f`; audit dependency advisories and distribution obligations before any adoption. [Pinned GOG handler](https://github.com/erri120/GameFinder/blob/efa23bd6d02ec07aa9fb1abe1025efafe3190d9f/src/GameFinder.StoreHandlers.GOG/GOGHandler.cs) [Package dependencies](https://www.nuget.org/packages/GameFinder.StoreHandlers.GOG/4.9.0#dependencies-body-tab)
- **Xbox deferred:** Start a separate metadata-only comparison using accessible Xbox library and package metadata. Package identity can identify an install; it cannot identify the process that owns an eligible window. Require fixtures for unavailable roots, inaccessible packages, missing manifests and same-name titles before selecting a reader. Keep WindowsApps ACLs intact. [GameFinder Xbox package](https://www.nuget.org/packages/GameFinder.StoreHandlers.Xbox/4.9.0)
- **EA/Origin deferred:** GameFinder's EA Desktop reader requires hardware-derived decryption and adds a wider dependency footprint. Verify a bounded read-only metadata source and a stable title identifier before adoption. Origin is legacy; only revisit if an actual supported installation justifies the reader. Ubisoft, Battle.net, Riot and Rockstar have no approved provider. [GameFinder provider documentation](https://github.com/erri120/GameFinder#supported-launchers)

### Decision output per provider
Record evidence URL + tag/commit + file/symbol, metadata source and schema, platform/ACL/access, stable key and executable limitations, absent/malformed/offline behavior, direct reader vs selected library (complexity, dependencies/license/security, scan IO, allocations, tests), recommended bounded implementation and owner validation. Use existing robust code when value exceeds cost; no package adoption without review. Research independently; approved implementation must pick explicit providers and test fixtures. Stop research once decision-ready; do not hold discovery hostage to every store. Steam/Epic regression and GOG decision are first; defer unsupported providers with reasons. Sources may include launcher local docs, source code, inspectable manifests; never scan real disk or scrape private accounts for research.

## Research responsibility and limits
ChatGPT can do public primary-source research independently, return source/link/pin, exact claim and uncertainty; Codex validates against real source/build and owns local fixture/compatibility. No repetitive internet sweeps if checked evidence remains valid; no unverified community claims as capability proof. Escalate only blocking ambiguity or high-risk dependency, and stop if licensing/permission/capability forbids implementation. Optional proposals are not authorized changes.
