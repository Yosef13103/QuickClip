## Game providers: previous evidence, not new benchmark
Old GameFinder 4.9.0 evaluation (Nov 13) restored .NET 9 libraries on .NET 10. GPL-3.0; re-audit corresponding source/notice obligations, transitives and advisories at chosen pin. Source: https://github.com/erri120/GameFinder/tree/v4.9.0 ; wiki https://github.com/erri120/GameFinder/wiki ; current README https://github.com/erri120/GameFinder . Current README documents Steam/GOG/Epic/EA/Origin/Xbox/Heroic, not all desired stores; no claim of current production compatibility. Existing QuickClip Steam/Epic readers preferred: GameFinder Epic does not supply LaunchExecutable in old evaluation. GOG 32-bit HKLM game ID/name/path/build/parent, valid build ID required; Xbox root markers and AppX manifests yield install metadata, not proof of eligible EXE; EA Desktop encrypted metadata and hardware-derived key (consider simpler read-only registry alternative); Origin legacy LocalContent manifests. GOG/Xbox are plausible selective adapters. Do not infer a game's executable from install metadata alone.

Historical synthetic GOG fixture: 500 installs + malformed row, empty registry returns none; first 11.08ms, warm 0.61ms mean/100, ~273KB allocated per call, +16.3MB private bytes/+17MB working set after loop. In-memory fixture only, no actual registry/tree scan, no direct-reader comparator. Old graph advisory audit clean then, not now. Common graph included FluentResults, Logging.Abstractions, NexusMods.Paths, OneOf, TransparentValueObjects; EA added SHA3.Net 2.0.0/System.Management 8.0.0; GOG/Origin RegistryUtils. Licensing and versions must be verified on actual selected graph, not inferred from this list.

### Decision output per provider
Record evidence URL + tag/commit + file/symbol, metadata source and schema, platform/ACL/access, stable key and executable limitations, absent/malformed/offline behavior, direct reader vs selected library (complexity, dependencies/license/security, scan IO, allocations, tests), recommended bounded implementation and owner validation. Use existing robust code when value exceeds cost; no package adoption without review. Research independently; approved implementation must pick explicit providers and test fixtures. Stop research once decision-ready; do not hold discovery hostage to every store. Steam/Epic regression and GOG decision are first; defer unsupported providers with reasons. Sources may include launcher local docs, source code, inspectable manifests; never scan real disk or scrape private accounts for research.
