### Audio A/B protocol (only if current defect suspected)
Owner-supervised 10–20s generated/consented sample, same codec/FPS/load/source, compare Sonar Chat vs physical headset Chat by changing only scratch QuickClip endpoint. Decode Chat track in independent player/FFprobe vs Editor; no private Discord sample upload. Record redacted endpoint type, rate/channels/sample format, peak/RMS, discontinuity/silent/timestamp-error counts, packet/sample drift. Isolate WASAPI → convert/mix → mux → playback. Repeat normal vs CPU-load if practical; no Windows format/default, effects, drivers or registry changes. Use real listening and PCM, not status alone.
