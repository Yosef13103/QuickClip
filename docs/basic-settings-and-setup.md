# Basic settings and guided setup — first candidate

One application and existing persisted settings schema. New Personal profiles default to Basic; existing profiles without the new presentation preference migrate to Advanced. Switching the presentation does not apply presets, restart recording, reset custom audio routing, or expand permission. Advanced retains the existing editing surfaces. Basic keeps current recording controls, resolution/quality/FPS, storage estimate and destination, audio selection and mic test, save hotkey, Games, General and notification previews; hides encoder/crop tuning, other hotkeys, library internals, sharing and diagnostics. Advanced audio endpoint selection is still available in Basic because the existing legacy routing cannot split arbitrary game/chat sounds.

Guided setup reuses those controls in nine steps. Changes save as edited. Back is on the left and Continue or Finish is on the right. Leaving Settings or closing the window pauses the guide at its saved step. A destination check that finishes after leaving cannot finish the guide or enable recording. Skip and rerun remain available. The final explicit enable checks a currently connected allowed display, recording hardware and a writable local folder. Recording changes only after settings persistence succeeds. Existing users can rerun while keeping their current recording preference.

Each Personal display has its own permission beside the display picker. It applies to both capture modes. Manual recording also needs deliberate session activation. Older profiles migrate active exact physical-display grants and honor existing exclusions. The old global permission cannot identify individual displays, so those users review the displays they want to allow. Basic retains Sharing, all shortcuts, clip and audio controls, feedback previews and Games readiness. Advanced exposes source management, track ordering and diagnostics.

This is the initial guided presentation, not a separate wizard engine or a completed UX review. Need combined integration with latest provider UI, owner visual/keyboard/DPI review and verify fresh/old/resumed profiles, custom routing and settings preservation, invalid folders, unavailable encoder/devices, permission and shortcut failures, notification previews, real save. Basic currently retains the full Games page and selected-device editor instead of introducing independent controls. No release approval.
