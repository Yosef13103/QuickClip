## Explicit exclusions / decisions
- No automatic achievement clips, auto-clipping from game events, League-specific match stats/KDA/items, per-game gameplay integrations, or event-system platform dependency. Optional generic event bookmarks only if a sufficiently general, reliable, supported source is found. Manual bookmarks remain. Never derive kill/death semantics from process/window state; no memory reading, game hooks for event data, unofficial API or OCR/ML project merely to label clips. Overwolf GEP is game-specific despite shared API: https://dev.overwolf.com/ow-native/live-game-data-gep/live-game-data-gep-intro/ ; not a universal solution. Candidate generic bookmark source must prove coverage, timestamps, event provenance, cost, opt-in; label 1x kill, 3x kills, death, round complete only if actual event verified. No automatic save, no match stats.
- No simultaneous multi-monitor recording/composition; keep selected single monitor, per-display permission and game-following. Optional one camera/PiP research only. No OBS-style general scene editor.
- No Flutter rewrite, wholesale OBS Studio dependency, custom injection mechanism, protected-content/anti-cheat bypass, forced theme or removal of existing advanced features. Respect Windows 10 supported capabilities and capture indicator. No telemetry/upload.
