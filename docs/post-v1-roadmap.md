## Shared constraints

- Personal development targets custom/main; main remains the clean upstream mirror. One writer per checkout, isolated branches/worktrees, review through PR; no automatic stable merge. Read latest protected branch SHA, avoid stale prompts, inspect prior implementation before modifying. Preserve GPL-3.0 compatibility and audit imported licenses. Keep commits reviewable.
- Windows 10 19045, Ryzen 5600X, RTX 3070, 32 GB, primary M34WQ 3440x1440 144 Hz, second BenQ 1920x1080 (DXGI sometimes reports 2400x1350). Sonar Game/Chat/Mic; preserve hybrid audio (default full mix + separate editable sources; exports mixed).
- Preserve installed production settings, clips, metadata, Steam library, external Gallery sources and SteelSeries Moments archive (E:\Stuff\Personal\Clips\SteelSeries Moments). No recursive cleanup or edits of owner recordings. Use disposable profiles and generated fixtures. Honor explicit source selection, verified physical monitor/window identity, master off, privacy and permissions. No anti-cheat bypass.
- Native C++ DDA/WGC/NVENC pipeline and C# WPF/libmpv frontend: GPU-first, low overhead, no CPU readback unless documented fallback; no per-frame UI or logs. Test both profiles in strict Windows CI; real hardware acceptance, resource measurements and actual visual inspection remain required. Never claim workload performance from headless CI.
- Preserve existing behavior and compatibility, add targeted regression tests; re-audit release code before implementing historical requests. Keep recording independent of frontend visibility.
